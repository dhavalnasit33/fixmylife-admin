# **App Name**: OneChat AI Admin Panel

## Core Features:

- Secure Authentication: Authentication system with role-based access control.
- Role-Based Dashboard: Dynamic dashboard with key metrics and role-specific quick actions.
- User Management: User management module with CRUD operations, role assignment, and detailed user views.
- Tool Category Management: Management interface for tool categories including creation, editing, and status toggling.
- AI-assisted Tool Management: Tool management with a dynamic form builder for custom tool creation and configuration. System prompt templates updated to align with changing business logic are verified via AI as a tool for suggesting appropriate wording. Tool
- AI Provider Management: AI provider management for configuring and monitoring AI services.
- Admin Analytics: Admin-level analytics dashboards, activity logs, and data export functionalities.

## Style Guidelines:

- Primary color: Indigo (#4f46e5) to reflect trust and intelligence.
- Background color: Light gray (#f9fafb) to provide a clean and modern feel.
- Accent color: Emerald (#10b981) for action items and positive feedback.
- Font: 'Poppins' (sans-serif) for a modern and readable interface.
- Card-based layout with 24px padding and 32px section margins for a structured view.
- Page transitions with fade in/out effects to provide smooth navigation.
- Clear and consistent icons for easy navigation and quick understanding.
